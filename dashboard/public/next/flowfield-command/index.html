    Flowfield Command help
    Field grammar
    This is a corridor diagram, not an orbital map. X is progress through workflow, Y separates concurrent run corridors, and Z separates agent currents. Bright moving particles are normalized events and tools, emitter clusters are agents, transverse amber planes are gates, the left basin is queued work, and red turbulence is an observed blocker.
    Selection and ownership
    Select a row in the semantic table to set context. The inspector filters telemetry by exact run ID and loads resources only through that selected run. A selected agent or blocker should always be resolved to its owning run before action.
    Requested versus observed
    Commands return accepted intent, not proof of completion. Pause and stop are checkpoint requests. Compare the requested control state with observed workflow phase, events, and command audit lifecycle.
    Incident safety
    Assess impact, inspect owning-run evidence, prefer mitigation, then investigate cause. Ask for deblock advice when uncertain. Advice is non-executing until separately approved. Current-run deblock cannot repair historical runs; branch their lineage instead.
    Stream and freshness
    Pause feed freezes browser-side updates without pausing workflow execution. Resume performs a reconciliation refresh. SSE falls back to polling. Freshness shows age of the latest message or refresh; stale data must not be treated as current.
    Commands and plans
    Every operation and plan action opens a review step. Destructive queue clearing requires the phrase CLEAR QUEUE. Plan creation includes boundaries, validation, gates, limits, repository, milestones, and lineage defaults. Plans move through review, approval, launch, clone, fork, and archive states using optimistic versions.

    Pointer and touch
    Drag the field to rotate; wheel or pinch is intentionally omitted to avoid trapping page zoom. Reset View restores the accessible default. All field information and selection are duplicated in the table.
    Accessibility and recovery
    Reduced-motion preference starts the field frozen. Freeze Motion controls only graphics; Pause Feed controls data updates. If WebGL2 is missing or its context is lost, the semantic controls remain active. A restored context reconstructs buffers automatically. Color is never the only status indicator.
