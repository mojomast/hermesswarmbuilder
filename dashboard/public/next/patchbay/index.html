Patchbay operating guide

Signal model

Modules are authoritative API domains. Cables show major signal, control, and evidence routes; they are not draggable configuration. Activate a module, object, or cable to inspect its source, destination, owning run, activity, evidence, and safe actions.

Keyboard

Press M to enter the patch field. Arrow keys move between modules. Tab reaches every control. Enter or Space inspects a focused module. Escape closes Help, the plan rack, or the inspector. Linear controls retain the same actions without visual cables.

Live telemetry

SSE carries state, events, and heartbeat messages. The masthead reports transport and age. Pause freezes the view and buffers events; Resume reconciles buffered and current state. Disconnect stops updates. Refresh performs a full API reconciliation.

Control safety

An accepted command is persisted intent, not proof that the runner has observed it. Confirm requested pause, stop, run-now, next-run, and loop state against the observed workflow in the inspector. Stop and pause normally take effect at a checkpoint.

Deblock and advice target the current blocked run only. Historical or terminal work is evidence-only: continue, fork, use as next direction, or clone/fork a reviewed project plan. Gate decisions record judgment; they do not manufacture required evidence.

Planning

Assistance is discussion and may use the configured inference provider. A proposal becomes mutable only after explicit conversion. Saved revisions are immutable review subjects; approval binds the exact digest, and launch requires explicit source-branch confirmation.
