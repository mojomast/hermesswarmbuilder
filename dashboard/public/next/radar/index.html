Operating Radar

Scope and flight strips

The scope is an orientation view. Range is deterministic workflow progress and bearing only separates marks. Select a track, blip, alert, or any flight-data-board row to open its authoritative strip. The strip identity never changes merely because another run becomes current.

Targets and evidence

Every run, agent, event, tool call, gate, queue item, iteration, plan, and blocker resolves to its owning run when one is reported. Evidence buttons carry that run explicitly. A missing run is shown as not reported rather than borrowing the current or previously selected run.

Recovery authority

Direct deblock and recovery advice apply only to the current run while it still reports a blocker. Historical or terminal work must continue through a new bounded continuation or fork using preserved lineage and evidence. Gate decisions record references; they do not create evidence artifacts.

Requested and observed state

Accepted commands are persisted control intent, not proof of completion. Pause and graceful stop normally take effect at a runner checkpoint. The footer and Authority strip keep requested state separate from observed workflow state. Destructive or broad commands require confirmation.

Live telemetry

Freeze display buffers stream data without pausing work. Unfreeze applies buffered events and performs a full synchronization. SSE automatically falls back to polling and reconnects. Signal age, last message, last refresh, transport, and errors are exposed so stale data is visible.

Plans and assistance

Flight plans support draft creation, immutable revisions, review, exact-revision approval or rejection, launch, clone, fork, and archive. Planning assistance is advisory and may use the configured inference provider; a proposal does nothing until an operator creates and advances a plan.

Keyboard and display

Tab reaches every control. Arrow keys, Home, and End move within the radar and tab strips; Enter or Space activates the focused mark. Escape closes dialogs. Mobile and zoomed layouts stack into one reading direction, while the scope remains a bounded two-dimensional figure. Reduced motion removes the sweep.
