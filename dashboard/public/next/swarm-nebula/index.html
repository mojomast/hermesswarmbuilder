    OPERATOR REFERENCE
    Swarm Nebula Manual
    
    
    
      
    Reading the nebula
    Large stars are runs. Agent beacons and bounded event/tool point clouds orbit the run they report. Cyan means agents, violet means events, amber means tool activity, and red wire shells indicate blockers. Position is deterministic visual grouping, not physical distance or causal certainty.
    
      
    Selection and camera
    Click or tap a star, beacon, particle, or shockwave to ray-pick it. Drag the canvas to rotate and use the wheel to zoom. The camera buttons provide the same operation. The Spatial index and Semantic view provide complete keyboard selection; Arrow keys move, Home/End jump, Enter/Space select. Inspector tabs use Left/Right Arrow with wraparound, Home, and End, and activate automatically.
    
      
    Transport and freshness
    Sync performs a full refresh. Freeze view calls the client display pause: streamed state and events are buffered while the displayed snapshot remains stable. Resume applies buffered data then synchronizes. Disconnect closes SSE and polling. Reconnect refreshes and reopens SSE; the client falls back to polling and retries SSE with backoff after failure. Telemetry age remains visible so stale data is never implied live.
    
      
    Workflow controls
    Pause, hold, stop, resume, and unhold are workflow commands, not transport controls. Requested state is shown separately from observed state. Pause and graceful stop can take effect only at runner checkpoints. Command accepted means persisted, not completed. Destructive or consequential commands require explicit confirmation.
    
      
    Blockers and recovery
    Current blockers may be targeted by deblock or inert deblock advice. Advice must be explicitly approved or denied. Historical blockers are evidence only: use an iteration continuation, fork, next direction, or a reviewed project plan. Swarm Nebula intentionally offers no unsupported agent or task retry.
    
      
    Queue, gates, showcase, lineage
    Use commands to add, pin, archive, or clear queue records; add/update gates, attach artifact references, and record decisions. Showcase loop controls expose target and observed generation. Iteration commands carry source run/iteration and bounded direction into continuation or fork requests.
    
      
    Plans and assistance
    Plans are persisted, versioned records. Create/update drafts, submit for review, approve or reject immutable revisions, then launch an approved revision. Clone, fork, and archive retain lifecycle semantics. Assistance can discuss and propose content but cannot save, approve, launch, or execute; conversion to a draft is explicit.
    
      
    Resources and accessibility
    Run inspection loads authoritative run details, artifacts, logs, SPEC, and DEVPLAN through the client. The semantic tables contain the same live objects and relationships as the canvas. Native controls, visible focus, status announcements, forced-colors support, and reduced-motion behavior are provided. Reduced motion stops orbital animation and shockwave expansion.
    
      
    Performance and recovery
    The renderer caps points at 1,500, event relationships at 1,000, device pixel ratio at 1.5, and drawing buffers near 4K. Background tabs stop animation. On WebGL context loss, the semantic interface remains operational; restoration rebuilds GPU resources from the current snapshot.
